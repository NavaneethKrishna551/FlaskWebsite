Ultrasonic sensor distance detection with arduino



A simple distance detection system that activates three colored leds at different lengths

I made it a long time ago and later attached an LCD display to it to show the exact distance

Pro(s)

Very simple and scalable.

Con(s)

Different reading based on material.

Items used
  1. Arduino UNO x1
  2. LCD screen module x1
  3. HC-SR04 Ultrasonic sensor x1
  4. Colored LEDs x3
  5. Jumpers and other wires

Temprature and humidity sensor project

Last year, for our schools science fest i made a simple DHT11 based Temprature and humidity module.
I used the DHT11 Temprature and humdity sensor connected to an arduino to measure the temprature.
To display this data i use an LCD module.

In my first version i connected it to arduino by simple
connecting all the 16 pins according to diagram online. This version was very unstable.
Due to using old jumper wires which had broken strands inside and rusted tips, even small
Could mess up the reading.

In my second version i used an I2C converter connected to the LCD which made it way easier to
connect and debug the project.

With this project i earned rank 1 in the sensor project category. Thus i was promoted to the
district level held in kattapana, in which i also earned 1st rank. So i was promoted to the
state level science fair held in malappuram. In which i got B grade.

I later Upgraded this with air quality checking using the MQ gas sensor.
